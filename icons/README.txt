SphynxVision website icon assets
================================

These SVG icons were created as custom line pictograms for the SphynxVision website.
They are not copied from a third-party icon library, stock icon marketplace, or AI-generated raster image set.

Use:
- Intended for use in this website and related SphynxVision web materials.
- Icons are simple SVG line artwork and are styled in index.html through CSS masks using the site theme colors.
- Keep this folder with index.html when publishing to GitHub Pages so the icon references continue to load.

Files in this folder are project-local assets.
